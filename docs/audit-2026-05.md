## 7) Risks and ambiguity to resolve before deletion

1. Some non-scheduling pages may belong to the requested top-level `Tools` bucket. They should be retained and relinked, not deleted.
2. Generated Supabase types include legacy fields even when runtime usage is gone. Removal should happen after schema cleanup migration.
3. A complete orphan DB object list requires a query callsite map and optional production telemetry.
